Things I've shipped

A ride-booking platform for a Nigerian fleet operator. I built it solo, from the database up: one Laravel 12 API serving a marketing site and two React and TypeScript apps, one for riders, one for staff across four roles.

  • Matches every ride to the nearest active, verified, idle driver. Cache locks and row-level locking mean no ride ever gets assigned twice. If a driver doesn't respond in time, it reassigns automatically.
  • Payments settle through Paystack webhooks. Booking status is a guarded state machine. Every action gets logged, and managers can export reports to CSV.
  • Built for shared hosting on purpose: a database queue drained by cron instead of a socket server. Not fancy, but it works, and it leaves room to grow.

A nomination and voting platform for an awards program. I built the Laravel API and the React frontend, nominees, categories, and a pay-per-vote system where every vote is a real Paystack transaction.

  • Nominees come in through a public form, and voting opens by category once nominations close. Nomination and voting deadlines are both configurable from the admin side.
  • Paystack handles the payment on every vote. A webhook confirms it, and a scheduled job re-checks anything the webhook missed, so a paid vote never just disappears.
  • The admin dashboard manages categories and nominees, shows live vote results, and can send bulk update emails to everyone involved.
